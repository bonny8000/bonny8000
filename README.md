## Selected Projects

### [Bonny Slide System](https://github.com/bonny8000/bonny-slide-generate-system)
繁中為主、英文為輔的 UX／產品簡報系統。包含版型、元件、內容路由、主題、驗證與 PDF 匯出工作流，讓研究與產品決策能被一致地轉化成清楚的故事。

### [Interview Analysis Skill](https://github.com/bonny8000/Interview-Analysis-Skill)
將原始訪談逐字稿清理、編碼並整理成可追溯的研究結論。強調逐句證據、反例掃描、參與者計數與不確定性的誠實標示。

### [Motion Skill](https://github.com/bonny8000/Motion-Skill)
用可重複使用的 stage、shape 與 beats 建立短篇產品動畫與 motion systems，支援可定位時間軸、版面稽核，以及 MP4／WebM／GIF 匯出。

## Design Principles

> **Evidence before decoration. Systems over one-offs. Clarity over complexity.**

- 先理解問題與證據，再決定畫面
- 把設計判斷寫進可維護的規則，而不是只留在成品裡
- 讓輸出可檢查、可追溯，也能被下一位協作者接手
- 在效率與品質之間，保留人的判斷與責任
